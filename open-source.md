## Featured

### milon/barcode

- **Downloads:** 16.2M
- **Downloads / month:** 595.6k
- **GitHub stars:** 1.5k
- **Forks:** 330
- **Stack:** PHP · Laravel
- **Packagist:** [https://packagist.org/packages/milon/barcode](https://packagist.org/packages/milon/barcode)
- **GitHub:** [https://github.com/milon/barcode](https://github.com/milon/barcode)

Barcode generation for Laravel and plain PHP. Wraps the TCPDF barcode engines (1D, QR, Data Matrix, PDF417) behind a small API that returns SVG, HTML, PNG, and JPEG — still maintained across current Laravel releases.
